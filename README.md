# 熊本 災害道路マップ β

地震・道路規制、洪水・冠水、土砂災害の情報を一つの地図で確認するWebアプリです。

画面表示バージョン：**V1.10**

## 現在の状態

第一弾の基本画面と主要な操作を実装しています。現在はローカルでの動作確認段階です。

## 第一弾の方針

- HTML・CSS・JavaScript・Leafletを使用する
- GitHub Pagesでの公開を想定する
- 熊本市周辺を初期表示する
- 洪水・土砂災害は国土地理院の公開タイルを表示する
- 道路・気象・河川情報は公式サイトへのリンクを中心にする
- 通行記録はブラウザのlocalStorageに保存する
- 地図をタップして、通行状態とメモを記録・編集・削除する
- 地図で場所を選び、記録ボタンを押した後に仮マーカーを確認して保存する
- 交通規制JSONを相対パスで読み込み、未接続と規制なしを区別する
- 初回確認ダイアログ、公式情報リンク、凡例を表示する
- Honda「通行実績情報マップ」とToyota「通れた道マップ」への公式リンクを表示する
- 道路の安全性や通行可能性を保証する表示は行わない

## 操作方法

1. 地図上の記録したい場所をクリックします。
2. 地図の下に表示される選択地点を確認します。
3. 「この選択地点を記録」を押すと、仮マーカーと入力画面が表示されます。
4. 「通れた・注意・通れなかった」を選びます。
5. 必要に応じてメモを入力します。
6. 保存します。

通行記録はブラウザのlocalStorageに保存されます。別端末とは共有されず、ブラウザデータの削除で消える可能性があります。

交通規制データは `data/traffic-restrictions.json` から読み込みます。初期状態は未接続であり、「規制なし」を意味しません。最新の道路情報は公式サイトで必ず確認してください。

## 交通量情報について

本アプリでは、GitHub PagesからCloudflare Workerを経由して、国土交通省/JARTIC系の交通量APIから交通量を取得します。

```text
GitHub Pages
  ↓ fetch
Cloudflare Worker
  ↓ fetch
xROAD/JARTIC交通量API
```

交通量データは常設トラフィックカウンター等の観測値です。交通量は参考値であり、道路の通行可否や安全性を保証するものではありません。災害時は、必ず道路管理者、JARTIC、自治体などの最新情報を確認してください。

5分間交通量は、観測後おおむね20分後に提供されます。API認証やブラウザからの直接取得が利用できない場合は、交通量APIを「認証設定が必要」と表示し、地図や利用者記録は継続して使えるようにしています。

5分値はリアルタイムそのものではなく、観測後おおむね20分後に提供されます。交通量APIの取得に失敗しても、地図、災害分類、現在地、通行記録、localStorageなどの基本機能は利用できます。

WorkerのURLは `https://disaster-road-traffic-api.rinrin8nana.workers.dev/` です。Workerのコードは `worker/traffic-volume-worker.js`、設定例は `worker/wrangler.toml.example` にあります。GitHub PagesからJARTIC APIへ直接接続せず、必ずWorkerを経由します。APIキーや認証情報はHTML・JavaScriptへ保存しません。

このサービスは、交通量API機能を使用していますが、サービスの内容は国土交通省によって保証されたものではありません。国土交通省API機能による交通量（参考値）を加工して作成しています。交通量は道路の通行可否・安全性を保証するものではありません。

## ローカルで確認する

このフォルダをWebサーバーで開いてください。`index.html`を直接開くより、Webサーバー経由での確認を推奨します。

```bash
python3 -m http.server 8123
```

ブラウザで `http://127.0.0.1:8123/` を開きます。

## GitHub Pagesで公開する

このフォルダをGitHubリポジトリのルートに置き、GitHub Pagesの公開元を設定します。`index.html`、`css/`、`js/`、`data/`を同じ構成で公開してください。APIキーやサーバー側処理は使用していません。
