# 熊本 災害道路マップ β 要件定義書

## 第一弾の目的

熊本県周辺の災害リスク情報と公式情報への入口を、一つのスマートフォン向け地図画面にまとめる。

本アプリは、安全な通行ルートや避難経路を保証するものではない。

## 必須機能

- Leafletと国土地理院タイルによる地図表示
- 熊本市周辺の初期表示
- 現在地表示
- 地域プルダウン検索
- 地震・道路規制、洪水・冠水、土砂災害の分類切替
- 洪水浸水想定区域（想定最大規模）の表示
- 急傾斜地の崩壊、土石流、地すべりの表示
- 半透明レイヤーと常時表示の凡例
- 地図選択後の通行記録登録
- 通れた・注意・通れなかったの状態選択
- メモ、編集、削除、全件削除
- localStorageへの保存と再読み込み後の復元
- 重要なお知らせと公式情報リンク
- 更新ボタン、取得失敗時の案内
- 初回免責事項ダイアログと画面下部の免責事項

## 外部情報の扱い

国土地理院の災害レイヤーは、公開タイルを直接読み込む方式を調査・実装する。

JARTIC、NEXCO西日本、国土交通省、気象庁、川の防災情報は、第一弾では公式リンクを基本とする。取得できない情報を仮データや最新情報として表示しない。

## 第一弾で実装しない機能

- ログイン・会員登録
- 利用者間の投稿共有
- 写真投稿・コメント投稿
- AIによる通行可否判定
- 自動ルート案内・避難ルート案内
- プッシュ通知
- 管理者画面
- 外部データベース
