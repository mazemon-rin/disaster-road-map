# 交通量API接続メモ

## 対象API

- ドメイン：`api.jartic-open-traffic.org`
- URI：`geoserver`
- レイヤー：`t_travospublic_measure_5m`
- 取得範囲：地図の現在表示範囲（BBOX）
- 道路種別：`3`（一般国道）
- 時間：現在時刻から25分、30分、35分前の5分単位を最大3回試行

## 認証と失敗時

仕様書では認証方式が「有」とされています。APIキー等の取得方法が設定されていない場合、アプリは交通量だけを「認証設定が必要」または取得失敗として表示します。利用者記録、災害レイヤー、公式リンクは停止しません。

APIキーや認証情報をHTML・JavaScriptへ保存しないでください。認証が必要な場合は、将来の中継処理へ分離します。

## 参考表示

合計交通量を次の暫定基準で表示します。

- 0〜20台：少なめ
- 21〜50台：普通
- 51台以上：多め

これはAPI仕様に基づく正式な混雑判定ではなく、初心者向けの参考表示です。「通れます」「安全です」などの判定には使いません。
